* Comparaciones (con operador ternario)
Escribir un programa que lea 2 números enteros e imprima: un 1 si uno de los números es igual a 8; 2 si los 2 números son iguales al 8.

#+BEGIN_SRC C
#include <stdio.h>

int main()
{
  int a, b;
  printf("Escriba 2 numeros enteros:\n");
  scanf("%i", &a);
  scanf("%i", &b);  

  // Como el resultado de una comparación es 1 (true) o 0 (false)
  // Podemos usar el 1 (true) para sumar el número de ochos.
  int resultado = (a == 8);
  resultado = resultado + (b == 8);
      
  printf("%i", (resultado == 2 ? 2 : 1));
    
  return 0;
}
#+END_SRC


* Años bisiestos (operadores de comparación y ternario)
/Un año es bisiesto si es divisible por 4 pero no por 100, o si es divisible por 400./
- Escriba un programa que indique si un número es bisiesto a partir de un número introducido por el usuario.
#+BEGIN_SRC C
#include <stdio.h>
int main()
{
  int x;
  int bisiesto;

  printf("Dime un número entero.\n");
  scanf("%i", &x);

  // Definimos la condicion de ser bisiesto
  // divisible por 4,     pero no por 100     ó     divisible por 400
  bisiesto = ((x % 4 == 0) && (x % 100 != 0)) || (x % 400 == 0);
 
  printf("En el anho %i febrero tiene %i dias\n", x, (bisiesto ? 29 : 28));
  return 0;
}
#+END_SRC
